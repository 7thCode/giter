giter

フォルダの変更を、かんたんに記録して、いつでも以前の状態に戻せるバージョン管理アプリ。Git の知識は要りません。

最新版: v0.1.0

macOS Apple Silicon / Intel (Universal) .dmg をダウンロード
Windows 64bit (x64) .exe をダウンロード
Linux AppImage / 64bit (x64) .AppImage をダウンロード

過去のリリース一覧は Releases から確認できます。

主な機能

  • Finder のようなフォルダ表示(リスト / アイコン)で、変更のあるファイルに「新規」「変更あり」の印を表示
  • ファイルをドロップして追加(コピー)、ドラッグして取り出し
  • 「保存」ボタンまたは ⌘S で、好きなタイミングにメモ付きで保存
  • 履歴から、ファイルやフォルダを以前の状態に戻す(戻す前の内容も失われません)
  • インターネット不要。すべてこの Mac / PC の中で完結します

初めて開くとき

  • macOS: 開発元が未署名のため、初回は Finder でアプリを右クリックして「開く」を選んでください。
  • Windows: SmartScreen の警告が出たら「詳細情報」→「実行」を選んでください。
  • Linux: ダウンロードしたファイルに実行権限を付けて起動してください(chmod +x)。
